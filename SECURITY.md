# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

Use GitHub's private vulnerability reporting for this repository. Include the affected version, reproduction steps, impact, and any suggested mitigation. Avoid including real credentials or personal data; if a credential may have been exposed, revoke or rotate it immediately.

If private vulnerability reporting is unavailable, open a public issue containing no vulnerability details and ask the maintainer to establish a private contact channel.

Security fixes are evaluated for the current release and the `main` branch. Maintainers will coordinate disclosure after a fix or mitigation is available.
